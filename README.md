
# Домашнее задание 1. Основы Python

В работе выполнены пять задач на использование базовых структур данных Python: списков, словарей и множеств.

## Задания

1. **hw1_task1.py** — операции над множествами товаров в Москве и Казани: общие товары, уникальные товары и общее количество разных товаров.

2. **hw1_task2.py** — анализ поисковых запросов: общее количество, частота каждого запроса, самый популярный запрос и его доля.

3. **hw1_task3.py** — анализ заказов: сумма возвратов, покупатели с возвратами, количество доставленных заказов и средний чек.

4. **hw1_task4.py** — анализ продаж по дням недели: общая выручка, день с максимальной выручкой, средняя выручка на заказ и доля возвратов.

5. **hw1_task5.py** — анализ отзывов о товарах: нормализация названий и расчёт средних оценок.

## Запуск

Для выполнения заданий необходим Python 3.9 или новее.

Все программы запускаются отдельно из корневой папки репозитория:

```bash
python hw1_task1.py
python hw1_task2.py
python hw1_task3.py
python hw1_task4.py
python hw1_task5.py
```

Сторонние библиотеки не требуются.
