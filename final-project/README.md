# Анализ Нобелевских лауреатов

Финальный проект по Python в рамках Avito Analytics Academy.

## Описание проекта

Проект посвящён обработке и анализу данных о Нобелевских лауреатах, полученных через официальный Nobel Prize API.

Исследование охватывает 1028 записей о лауреатах. Анализ выполнен средствами Python без использования pandas и numpy.

## Реализованные задачи

- Загрузка данных из API с поддержкой пагинации.
- Обработка вложенных JSON-словарей с помощью конфигураций.
- Технический EDA: анализ пропусков, дубликатов и идентификаторов.
- Исследование распределения лауреатов по странам и категориям премий.
- Анализ возраста получения первой Нобелевской премии.
- Исследование гендерного распределения по категориям и десятилетиям.
- Визуализация основных результатов с помощью matplotlib.
- Бонусное задание: анализ частоты слов в текстах мотиваций вручения премий.

## Структура проекта

- `laureates_countries_task.ipynb` — основной ноутбук с анализом и выводами.
- `json_dict_processing.py` — универсальная обработка вложенных словарей.
- `prizes_configs.py` — конфигурация обработки премий.
- `laureates_configs.py` — конфигурации обработки людей и организаций.
- `dataset_helpers.py` — фильтрация, группировка и вспомогательные функции.
- `aggregations.py` — функции статистических агрегаций.
- `stopwords.py` — список стоп-слов для текстового анализа.

## Запуск проекта

1. Установить зависимости:

   ```bash
   pip install requests matplotlib
   ```

2. Открыть `laureates_countries_task.ipynb` в Jupyter Notebook или PyCharm.
3. Выполнить все ячейки по порядку.

Для загрузки данных необходимо подключение к интернету.

## Основные результаты

- Наибольшее количество лауреатов родилось в США — 299 человек.
- Средний возраст получения первой премии составляет 60,61 года.
- Наиболее высокий средний возраст награждения наблюдается в экономике, наиболее низкий — в физике.
- Женщины составляют 6,9% лауреатов-людей за рассматриваемый период.
- Доля женщин среди лауреатов в последние десятилетия увеличивается.

## Источник данных

Официальный Nobel Prize API: https://api.nobelprize.org/2.1/laureates

Данные актуальны на момент выполнения проекта — ноябрь 2026 года.
