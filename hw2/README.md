
# Домашнее задание 2. Функции в Python

Программа формирует отчёты по сотрудникам на основе файла Corp_Summary.csv.

## Варианты отчётов

1. Иерархия департаментов и отделов.
2. Количество сотрудников, минимальный, максимальный и средний оклад по каждому департаменту.
3. Сохранение сводки по департаментам в CSV-файл.

## Запуск

Перейти в папку hw2:

```bash
cd hw2
```

Запуск нужного варианта:

```bash
python corp_reports.py 1
python corp_reports.py 2
python corp_reports.py 3
```

Третий вариант создаёт файл department_summary.csv.

Для работы необходим Python 3.9 или новее. Сторонние библиотеки не используются.
